## 已解决的检查问题

RSS peer 冲突、工程识别元数据、Python 文件被 Hexo 当 JS 加载、Stylus 缺失 @extend、旧图片/链接过滤器、头像资源覆盖与体积超限均已处理，见 shoka-restoration.md。

另发现：在旧预览服务仍运行时执行清理/生成，服务退出可能把内存中的旧正文缓存写回 db.json，导致静态成品正确、预览仍有旧 data-src。最终采用“停止服务 → npm run check → 重新启动预览”验证，图片 src 已正常。修改渲染器后应使用这个顺序，不并行重建与关闭旧服务。
